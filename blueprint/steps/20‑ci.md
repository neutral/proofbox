## Objective

Wire GitHub Actions for linting and test coverage ≥ 80 %.

## Implements

- **Non‑Functional Goals – Simplicity/Maintainability** (CI keeps codebase healthy) and **Open questions – Concurrency & Caching** (CI will later run race tests).
  _What happens_:

  - Adds lint, vet, tests, and coverage gating. ≥ 80 % coverage concretely enforces "documentation and test quality" from original step 10.

## Technical Details

### Comprehensive CI/CD Pipeline

The CI pipeline ensures code quality, correctness, and performance consistency:

1. **Pipeline Stages**
   - Code Quality (lint, format, vet)
   - Unit Tests (with race detection)
   - Integration Tests (Pebble persistence)
   - Benchmarks (performance regression)
   - Coverage Analysis (≥80% requirement)
   - Security Scanning (dependencies)
   - Documentation Build

2. **Build Matrix**
   - Go versions: 1.21, 1.22, 1.23
   - OS: Linux, macOS, Windows
   - Architecture: amd64, arm64

### GitHub Actions Configuration

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

env:
  GO_VERSION: '1.22'
  COVERAGE_THRESHOLD: 80

jobs:
  lint:
    name: Lint and Format
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          
      - name: Install tools
        run: |
          go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest
          go install golang.org/x/tools/cmd/goimports@latest
          go install github.com/google/addlicense@latest
          
      - name: Check formatting
        run: |
          if [ "$(gofmt -s -l . | wc -l)" -gt 0 ]; then
            echo "Files need formatting:"
            gofmt -s -l .
            exit 1
          fi
          
      - name: Check imports
        run: |
          if [ "$(goimports -l . | wc -l)" -gt 0 ]; then
            echo "Files need import formatting:"
            goimports -l .
            exit 1
          fi
          
      - name: Run golangci-lint
        run: golangci-lint run --timeout=5m
        
      - name: Check licenses
        run: addlicense -check -c "ProofBox Contributors" -l MIT **/*.go

  test:
    name: Test
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest]
        go: ['1.21', '1.22', '1.23']
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ matrix.go }}
          
      - name: Run tests
        run: |
          go test -v -race -coverprofile=coverage.txt -covermode=atomic ./...
          
      - name: Check coverage
        run: |
          coverage=$(go tool cover -func=coverage.txt | grep total | awk '{print $3}' | sed 's/%//')
          echo "Coverage: $coverage%"
          if (( $(echo "$coverage < $COVERAGE_THRESHOLD" | bc -l) )); then
            echo "Coverage $coverage% is below threshold $COVERAGE_THRESHOLD%"
            exit 1
          fi
          
      - name: Upload coverage
        if: matrix.os == 'ubuntu-latest' && matrix.go == env.GO_VERSION
        uses: codecov/codecov-action@v4
        with:
          file: ./coverage.txt

  integration:
    name: Integration Tests
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          
      - name: Run integration tests
        run: |
          go test -v -tags=integration ./tests/integration/...
          
      - name: Test with large dataset
        run: |
          go test -v -run=TestLargeDataset -timeout=30m ./tests/stress/...

  benchmark:
    name: Benchmarks
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          
      - name: Run benchmarks
        run: |
          go test -bench=. -benchmem -run=^$ ./bench/... | tee benchmark.txt
          
      - name: Store benchmark result
        uses: benchmark-action/github-action-benchmark@v1
        with:
          tool: 'go'
          output-file-path: benchmark.txt
          github-token: ${{ secrets.GITHUB_TOKEN }}
          auto-push: true
          
      - name: Check performance regression
        run: |
          # Compare with baseline benchmarks
          go run ./tools/bench-compare/main.go benchmark.txt

  security:
    name: Security Scan
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Run gosec
        uses: securego/gosec@master
        with:
          args: ./...
          
      - name: Run govulncheck
        run: |
          go install golang.org/x/vuln/cmd/govulncheck@latest
          govulncheck ./...

  build:
    name: Build Artifacts
    runs-on: ubuntu-latest
    needs: [lint, test]
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          
      - name: Build binaries
        run: |
          GOOS=linux GOARCH=amd64 go build -o dist/proofbox-linux-amd64 ./cmd/proofbox
          GOOS=darwin GOARCH=amd64 go build -o dist/proofbox-darwin-amd64 ./cmd/proofbox
          GOOS=windows GOARCH=amd64 go build -o dist/proofbox-windows-amd64.exe ./cmd/proofbox
          
      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: binaries
          path: dist/
```

### Local Development Support

```makefile
# Makefile
.PHONY: ci-local lint test coverage

ci-local: lint test coverage

lint:
	@echo "Running linters..."
	@golangci-lint run
	@gofmt -s -l . | grep -v vendor | tee /dev/stderr | ifne false
	@go vet ./...

test:
	@echo "Running tests..."
	@go test -v -race ./...

coverage:
	@echo "Checking coverage..."
	@go test -coverprofile=coverage.out ./...
	@go tool cover -html=coverage.out -o coverage.html
	@go tool cover -func=coverage.out | grep total

race:
	@echo "Running race detector..."
	@go test -race -short ./...
```

## Implementation Steps

1. **Create GitHub Actions Workflows**
   - Main CI pipeline (.github/workflows/ci.yml)
   - Release workflow (.github/workflows/release.yml)
   - Nightly benchmarks (.github/workflows/nightly.yml)

2. **Configure Linting Tools**
   ```yaml
   # .golangci.yml
   linters:
     enable:
       - gofmt
       - golint
       - govet
       - gosec
       - ineffassign
       - misspell
       - unconvert
       - gocritic
       - gocyclo
       - dupl
   ```

3. **Add Test Scripts**
   - Unit test runner with coverage
   - Integration test suite
   - Stress test scenarios
   - Benchmark comparisons

4. **Setup Badge Generation**
   - CI status badge
   - Coverage percentage badge
   - Go Report Card integration

5. **Add Pre-commit Hooks**
   ```yaml
   # .pre-commit-config.yaml
   repos:
     - repo: local
       hooks:
         - id: go-fmt
         - id: go-test
         - id: go-lint
   ```

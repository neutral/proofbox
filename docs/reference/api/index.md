# ProofBox API Reference

This directory contains the raw public API signatures for all ProofBox packages.

## Package API Documentation

- [tree.md](tree.md) - Tree package APIs (core JMT implementation)
- [types.md](types.md) - Types package APIs (core data types)
- [storage.md](storage.md) - Storage package APIs (storage backends)
- [proof.md](proof.md) - Proof package APIs (cryptographic proofs)
- [codec.md](codec.md) - Codec package APIs (node encoding/decoding)
- [crypto.md](crypto.md) - Crypto package APIs (hashing utilities)
- [metrics.md](metrics.md) - Metrics package APIs (monitoring)

## Notes

These files contain only the raw Go signatures of all exported (public) APIs, without additional documentation or examples. They serve as a quick reference for available types, functions, methods, and constants in each package.

For detailed usage examples and documentation, refer to the other documentation sections or the source code comments.
